# Arrays

## Overview

This project mirrors a subset of methods from the Java utility class, util.Arrays.

## Requirements

| Software                | Version   |
|:------------------------|:----------|
| Apache Maven            | >=3.9.9   |
| OpenJDK Development Kit | >=21.0.12 |

## Examples

### Spotless

```shell
mvn spotless:apply
```

### Checkstyle

```shell
mvn checkstyle:check
```

### JUnit

```shell
mvn test
```

### JMH

```shell
mvn clean package
java -jar target/Arrays-1.0.0-SNAPSHOT.jar
```

### JavaDoc

```shell
mvn javadoc:javadoc
```
